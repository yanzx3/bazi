# 铁板神数八字命理推演技能

## 简介

这是一个基于传统《铁板神数》《皇极经世》《易经》的八字命理推演技能，
为 OpenClaw Hub 提供严谨、精准的命理分析服务。

## 核心特点

✨ **三阶段严谨工作流**
- 信息采集 → 定刻验证 → 正断详批
- 绝不跳步，确保精准

✨ **传统命理正宗**
- 铁板神数古典条文体
- 定刻、校刻、详批传统流程

✨ **可验证预测**
- 通过已发生事件反证时辰
- 所有判断可被现实验证

## 快速开始

### 1. 加载技能
将 `bazi-divination` 目录放入 OpenClaw Hub 技能目录即可。

### 2. 触发方式
发送以下任意关键词：
- 八字
- 命理
- 铁板神数
- 算命
- 排盘
- 运势
- 流年
- 大运

### 3. 交互流程

**第一步：提供生辰信息**
```
用户：帮我算八字
AI：请提供出生年月日时、性别...
```

**第二步：验证时辰**
AI会询问2-3个已发生事件的验证问题

**第三步：获取详批**
验证通过后，AI将输出万字详批报告

## 输出内容

详批报告包含四大板块：

### 1. 命理解读
- 性格特质
- 事业财运
- 婚姻感情
- 健康提示
- 六亲缘分

### 2. 专项分析
- 婚姻感情详析
- 事业财运详析
- 健康状况详析
- 子女运势详析
- 学业考试详析

### 3. 大运流年
- 大运排列与关键节点
- 当前运势分析
- 近三年流年详批（每月运势+量化打分）
- 近期流年提示

### 4. 建议指南
- 开运指南（方位、颜色、行业、数字）
- 注意事项（小人特征、忌讳行为）
- 具体建议（趋吉避凶之法）

## API 接口

**接口地址：** `https://www.ai2api.top/bazi/`

**请求参数：**
- `year`: 出生年份
- `month`: 出生月份
- `day`: 出生日期
- `hour`: 出生小时
- `minute`: 出生分钟（可选）
- `gender`: 性别（male/female）
