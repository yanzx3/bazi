# 八字命理推演技能 - 项目文档

## 项目概述

这是一个基于传统《铁板神数》《皇极经世》《易经》的八字命理推演技能，
旨在为 OpenClaw Hub 用户提供严谨、精准的命理分析服务。

## 核心特性

### 1. 三阶段严谨工作流
- **阶段0 信息采集**：收集生辰信息，调用API排盘
- **阶段1 定刻验证**：通过反证问题验证时辰准确性
- **阶段2 正断详批**：输出万字详批，涵盖四大板块

### 2. 传统命理正宗
- 承袭铁板神数一脉
- 使用古典条文体（如"先天注定，父相属龙"）
- 严格遵循定刻、校刻、详批的传统流程

### 3. 可验证的预测
- 所有判断必须可被现实事件验证
- 年份预测采用"主应年 + 次应年"精准断法
- 通过已发生事件反证时辰准确性

## 技术架构

### API 依赖
- **八字排盘API**: https://www.ai2api.top/bazi/
- 返回完整八字数据：四柱、五行、十神、大运、流年、神煞

### 数据流程
```
用户输入生辰 
    ↓
调用 API 获取八字数据
    ↓
分析时辰旺衰，精确定刻
    ↓
提出反证问题验证
    ↓
用户确认后万字详批
    ↓
输出四大板块分析报告
```

## 使用方式

### 1. 在 OpenClaw Hub 中加载
将 `bazi-divination` 目录上传至 OpenClaw Hub 的技能目录即可。

### 2. 触发技能
用户可通过以下关键词触发：
- 八字
- 命理
- 铁板神数
- 算命
- 排盘
- 运势
- 流年
- 大运
- 合婚

### 3. 交互流程

**首次对话：**
AI将以命理大师身份问候，询问出生信息

**信息收集：**
- 出生年月日时（公历/农历）
- 出生分钟（用于精确定刻）
- 性别

**定刻验证：**
AI会提出2-3个基于已发生事件的反证问题
例如：父母生肖、早年灾厄、兄弟姐妹数量等

**正断详批：**
用户确认验证问题后，AI将输出万字详批：
1. 命理解读（性格、事业、婚姻、健康）
2. 专项分析（婚姻、事业、健康、子女、学业）
3. 大运流年（十年大运、逐年流年、月度分析）
4. 建议指南（开运方位、注意事项、具体建议）

## 输出格式示例

### 古典条文体示例
```
铁板判曰："日主庚金，性刚果决，有勇有谋。"
先天注定，父相属龙，身居高位。
兄弟三人，一雁孤飞。
夫妻宫旺，琴瑟和鸣。
财官双美，富贵可期。
```

### 流年详批示例
```
【2025年 · 36岁】
铁板判词："太岁当头坐，无喜必有祸"
白话详解：
- 整体运势：65分（中等偏下，需谨慎）
- 情感运势：夫妻宫受冲，易有口角，宜忍让
- 事业财运：变动之象，不宜重大投资
- 健康状况：注意肝胆，避免熬夜
- 每月运势：
  正月：运势平平，宜守不宜攻 [60分]
  二月：贵人出现，可谋小成 [75分]
  ...
```

## 注意事项

### 对AI的要求
1. **绝不跳步**：必须按阶段0→1→2顺序执行
2. **等待确认**：阶段1提问后必须停顿等待用户回复
3. **重新定刻**：验证不符时必须推翻重来
4. **万字详批**：阶段2输出必须详尽完整
5. **古典文风**：使用铁板神数古典条文体

### 对用户的提示
1. 准确的出生时间（尤其是时辰）对推演至关重要
2. 验证问题的准确回答有助于精确定刻
3. 命理分析仅供参考，人生仍需自己把握
